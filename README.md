# Mona's Baking: packaging brand visualization

Static site: 3D fold-up boxes, flat dielines with mm / cm / in, stickers, bag, cups and a logo size tool.
Open `index.html` through any static server (no build step).

All sizes are design values. Nothing here has been validated by a manufacturer or printer.
`src/` holds the Python generators (they expect the original project folders next to `site/`).
